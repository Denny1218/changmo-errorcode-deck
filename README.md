# 창모 에러코드 배치표

창세기전 모바일 **에러코드(디에네 · 아수라 혼령)** 1덱/2덱 배치표를 만들고, 이미지·엑셀로 공유하는 도구입니다.

**바로 쓰기: https://denny1218.github.io/changmo-errorcode-deck/**

내려받아 쓰려면 `index.html` 을 크롬/엣지로 열면 됩니다.
공지 데이터(`data.js`)는 매일 새벽 3시에 자동으로 갱신됩니다 (Actions → "공지 데이터 갱신").

## 주요 기능

- **시즌 정보 자동 표시** — 업데이트 공지에서 시즌별 입장 속성, 버프/디버프, 전투 일정을 가져옵니다.
- **배치판** — 디에네(양옆 4 + 정면 3×3 = 13자리), 아수라(양옆 8 + 정면 3×2 = 14자리) 자리 그대로. 클릭하거나 끌어서 배치합니다.
- **장비표 자동 채움** — 캐릭터를 놓으면 그 캐릭터의 지난번 AI·클래스·스킬·무기·방어구·악세·아티팩트가 채워집니다.
- **선택 목록** — 클래스(전직 트리), 아티팩트, 스킬을 캐릭터별 목록에서 고릅니다.
- **1덱·2덱 중복 경고**, 1안/2안 복제, 지난 배치 가져오기.
- **공유** — 이미지 복사(카톡/디스코드에 바로 붙여넣기), PNG 저장, 엑셀 저장.
- **캐릭터 관리 (공용)** — 줄임말, 속성, 클래스, 전용 무기, 아티팩트, 스킬을 누구나 고치고 추가하며, 모든 기기·모든 사람에게 같은 정보로 보입니다. 수정 기록이 남아서 잘못 고친 건 되돌릴 수 있습니다.
- **게시판** — 짠 배치를 [게시]로 올리면, 글 암호를 아는 사람만 열어 보고 내 편집 화면으로 불러올 수 있습니다. 불러와서 고친 뒤 같은 글로 다시 게시할 수 있습니다. 내용은 브라우저에서 글 암호로 암호화되어 저장됩니다.
- **관리자** — 관리자 코드를 넣은 기기는 모든 글을 지우고, 장난친 기기의 편집을 막을 수 있습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 배치표 화면 |
| `data.js` | 업데이트 공지에서 모은 캐릭터·장비·시즌 정보 (`update-data.bat` 로 갱신) |
| `skills.js` | 나무위키에서 모은 캐릭터별 스킬, 공지에 없는 속성·전직 트리 |
| `seed.js` | 처음 열 때 쓰는 초기 배치·장비 기록 |
| `update-data.bat` / `update-data.ps1` | 네이버 게임 라운지 업데이트 게시판을 읽어 `data.js` 를 다시 만듦 |
| `online.js` / `firebase-config.js` | 공용 캐릭터 정보·게시판 (Firebase Firestore, 익명 로그인) |
| `firestore.rules` | Firestore 보안 규칙 (Firebase 콘솔 → Firestore → 규칙 에 붙여 넣음) |

## 매주 쓰는 순서

1. 새 공지가 올라오면 `update-data.bat` 실행 → `index.html` 새로고침
2. 위에서 시즌 선택 → "지난 배치 가져오기" → 바뀐 부분만 수정
3. "이미지 복사" 후 붙여넣기

배치와 장비 기록은 각자 브라우저에 저장됩니다(공유하려면 [게시]). 가끔 **백업/복원 → 백업 파일 받기** 로 백업해 두세요.
